# BudMachine

**BudMachine** — рабочая база знаний и система подготовки экспертного SEO-контента о строительстве, ремонте, отделочных работах и машинной штукатурке.

Проект объединяет единые редакционные правила, SEO-подход, контроль качества, требования к визуалам и шаблоны для выпуска материалов на русском и украинском языках.

## Принцип работы

Для каждой статьи:

1. Заполните входные данные: тема, язык, страна или регион, аудитория, цель, ключевой запрос и ограничения.
2. Используйте Master Prompt вместе с актуальными гайдами.
3. Подготовьте материал, метаданные, ссылки и визуальный бриф.
4. Выполните QA-проверку перед публикацией.

Правила базы применяются в таком порядке: достоверность и безопасность → центральные документы проекта → входные данные статьи → редакционные предпочтения конкретного материала.

### Гайды

В папке [Guides](Guides/) находятся действующие правила проекта:

- редакционный гайд;
- SEO-гайд;
- гайд терминологии и локализации;
- гайд визуального контента;
- QA-гайд;
- Anti-AI гайд.

Начинайте с [индекса базы знаний](Guides/README.md).

## Статус

База гайдов опубликована. Следующие документы для подготовки:

- `Master Prompt.md` — единый рабочий промпт для создания статей;
- `Content Engine.md` — Markdown-версия центральной спецификации;
- `Knowledge Base.md` — навигация и правила использования базы;
- шаблоны статей и визуальных брифов;
- утверждённые примеры статей на русском и украинском языках.

## Версионирование

При существенном изменении правил обновляйте соответствующий гайд и добавляйте запись в `Guides/Update Log.md`.
