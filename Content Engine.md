# BudMachine Content Engine v1.0

## Назначение

Content Engine — простой рабочий алгоритм подготовки материалов BudMachine.

Он не заменяет `Master Prompt.md` и отдельные гайды. Его задача — определить последовательность действий от постановки задачи до готового материала.

## Рабочий процесс

### 1. Получение задачи

Определить:

- тему;
- язык;
- страну и регион, если они важны;
- целевую аудиторию;
- основной поисковый запрос, если он уже задан;
- объём;
- дополнительные требования.

Если критически важной информации не хватает — запросить уточнение.

### 2. Анализ

Определить:

- поисковый интент;
- проблему пользователя;
- результат, который он ожидает получить;
- основные вопросы, которые должна закрыть статья.

Если доступен веб-поиск:

- проанализировать ТОП-10 Google;
- изучить актуальные авторитетные источники;
- найти пробелы в материалах конкурентов;
- проверить актуальность важных фактов.

Не имитировать анализ, если доступ к поиску отсутствует.

### 3. Семантика

Подготовить:

- основной ключ;
- дополнительные Keywords;
- предварительную группировку Keywords на ВЧ, СЧ и НЧ, если доступны данные для такой оценки;
- LSI-запросы и тематические термины.

Не выдумывать значения поисковой частотности.

### 4. План статьи

Подготовить:

- Title;
- Description;
- H1;
- основной ключ;
- Keywords ВЧ/СЧ/НЧ;
- LSI;
- структуру H2/H3;
- назначение каждого раздела;
- дополнительные вопросы;
- предложения по таблице, FAQ и изображению, если они нужны.

### 5. Утверждение плана

Передать план пользователю.

**Не писать полный текст статьи до утверждения плана.**

Если пользователь вносит изменения:

1. обновить план;
2. снова передать его пользователю;
3. дождаться утверждения.

### 6. Написание

После утверждения плана подготовить:

- Title;
- Description;
- H1;
- статью;
- FAQ, если он нужен;
- заключение;
- рекомендации по внутренней перелинковке;
- внешний источник;
- ALT;
- Image Title;
- Image Prompt.

При написании использовать правила из соответствующих гайдов.

### 7. Визуальный материал

Подготовить один основной Image Prompt и связанные с ним ALT и Image Title.

Технические параметры, размер и визуальные требования брать из `Guides/Visual Guide v1.0.md`.

### 8. Anti-AI проверка

После написания выполнить отдельную редакторскую проверку по `Guides/Anti-AI Guide v1.0.md`.

Устранить шаблонность, смысловые повторы, однообразный ритм и другие признаки искусственно построенного текста.

### 9. QA

Провести финальную проверку по `Guides/QA Guide v1.0.md`.

Проверить:

- SEO;
- структуру;
- факты;
- терминологию;
- читаемость;
- Anti-AI;
- перелинковку;
- визуальный блок;
- критические ошибки.

### 10. Результат

Материал считается готовым только после прохождения финальной проверки.

Возможные статусы:

- `PASS` — готово;
- `PASS WITH NOTES` — готово, но есть необязательные замечания;
- `RETURN` — требуется исправление или уточнение.
