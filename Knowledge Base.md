# BudMachine Knowledge Base

Версия: 1.0

## Назначение

Knowledge Base — центральная точка входа в правила BudMachine. Она не дублирует гайды, а помогает выбрать нужные правила для подготовки и проверки материала.

## Порядок применения правил

При конфликте правила применяются в следующем порядке:

1. Закон, безопасность, правила платформы и достоверность.
2. Центральные документы проекта: этот файл, `Master Prompt.md` и `Content Engine.md`.
3. Актуальные гайды из папки `Guides/`.
4. Входные данные конкретной статьи.
5. Редакционные предпочтения для конкретного материала.

Если конфликт нельзя устранить без риска недостоверности или нарушения правил, материал получает статус `RETURN` до уточнения.

## Рабочий процесс

1. Определить тему, язык, локаль, аудиторию, цель и ограничения материала.
2. Установить основной поисковый интент и ключевой запрос.
3. Составить план статьи по редакционному и SEO-гайдам.
4. Подготовить текст, метаданные, ссылки и визуальный бриф.
5. Проверить терминологию, локализацию, факты и источники.
6. Выполнить QA- и Anti-AI-проверку.
7. Присвоить статус: `PASS`, `PASS WITH NOTES` или `RETURN`.

## Поддержка базы

- Изменяйте правила в профильном гайде, а не копируйте их в несколько документов.
- При существенных изменениях фиксируйте запись в `Guides/Update Log.md`.
- Не добавляйте новые документы, пока существующие гайды не покрывают задачу недостаточно.
- `Master Prompt.md` должен ссылаться на правила базы, а не повторять их полностью.
