# Terminology Guide v1.0

## Terminology and Units Policy

В материалах BudMachine используются общепринятые строительные и технические термины. При необходимости их значение сверяется с авторитетными справочными источниками, включая Википедию.

Технические характеристики, названия материалов, оборудования и технологий проверяются по официальной документации производителей, техническим паспортам и действующим нормативам.

Все размеры, веса, объёмы и другие величины указываются в метрической системе. Для физических и химических величин применяется Международная система единиц (СИ).

Не допускается придумывать термины, использовать нестандартные сокращения без расшифровки или заменять точные технические понятия рекламными формулировками.

## Contextual Terminology Variation

BudMachine не должен механически повторять одно и то же техническое слово в каждом предложении. Для повышения естественности текста допускается использовать контекстуально корректные синонимы, близкие технические обозначения и словосочетания из двух-трёх слов.

Такая замена применяется только тогда, когда новое выражение сохраняет исходный смысл. Нельзя заменять термин случайным синонимом только ради снижения повторов или показателя заспамленности.

Если точный термин необходим для технической точности, его нельзя заменять ради разнообразия.

### Пример: «штукатурка»

В зависимости от контекста вместо повторяющегося слова «штукатурка» могут использоваться:

- штукатурный состав;
- штукатурная смесь;
- отделочный состав;
- штукатурный слой;
- выравнивающий слой;
- отделочный слой;
- штукатурное покрытие;
- нанесённый слой;
- получаемая поверхность;
- готовая поверхность;
- обработанная поверхность;
- гипсовый слой;
- гипсовая поверхность;
- цементный слой;
- цементно-известковый слой;
- цементно-известковая поверхность.

Слова «раствор», «смесь» и «состав» используются только тогда, когда контекст действительно допускает такую замену. «Раствор» не следует использовать как универсальный синоним любого штукатурного материала.

Слово «облицовка» не считать универсальным синонимом «штукатурки»: оно имеет другое техническое значение и используется только в соответствующем контексте.

### Пример: «условия»

В зависимости от смысла вместо повторяющегося слова «условия» могут использоваться:

- среда;
- рабочая среда;
- обстановка на объекте;
- режим работы;
- технологический режим;
- температурный режим;
- параметры работы;
- параметры объекта;
- факторы;
- исходные параметры;
- требования к выполнению работ;
- особенности объекта.

Важно различать значение слов. «Требования» — это не прямой синоним «условий», если речь идёт о нормативном или техническом предписании. «Факторы» подходят, когда речь идёт о причинах или влияющих обстоятельствах. «Режим» подходит, когда описывается установленный порядок или диапазон выполнения работ.

## Rules for Use

1. Сначала определяется точный смысл исходного термина.
2. Затем выбирается только тот вариант, который сохраняет этот смысл.
3. В пределах одного абзаца не следует без причины чередовать несколько терминов для одного объекта, если это может запутать читателя.
4. В соседних предложениях допустима естественная вариативность, если объект остаётся однозначно понятным.
5. Одно слово можно заменить естественным словосочетанием из двух-трёх слов, если это улучшает ритм и точность текста.
6. Важные профессиональные термины не заменяются полностью: ключевой термин должен периодически сохраняться для технической ясности и тематической релевантности.
7. Синонимы не должны использоваться искусственно только для снижения показателя Text.ru.
8. Приоритет всегда имеют точность, понятность и соответствие строительному контексту.

## Ongoing Terminology Expansion

Этот раздел является расширяемым. По мере редакторских проверок в него добавляются повторяющиеся технические слова и проверенные контекстуальные варианты их употребления.

Новые варианты добавляются только после проверки их технической корректности и различий в значении.
