# BudMachine — Source Priority Guide

## Приоритет источников для украинских статей

Для статей, ориентированных на Украину, приоритет имеют украинские первичные и официальные источники.

При выборе внешних источников использовать следующий порядок:

1. Официальные украинские государственные ресурсы и нормативная база Украины.
2. Официальные украинские строительные ресурсы, включая Єдину державну електронну систему у сфері будівництва.
3. Официальная техническая документация производителя материала, опубликованная для украинского рынка.
4. Другие проверенные украинские первичные источники.
5. Зарубежные первичные источники — только если соответствующая информация отсутствует в украинских первичных источниках и действительно необходима для раскрытия темы.

Российские нормативные, государственные и технические ресурсы не используются как источники для украинских статей.

Не следует подменять украинскую нормативную базу зарубежными документами, если требуемая информация доступна в Украине.

Если украинский нормативный документ не регулирует конкретный вопрос, это нужно прямо учитывать в формулировках. Нельзя приписывать нормативу требования, которых в нём нет.

Для технических параметров конкретной смеси приоритет имеет актуальная техническая документация именно на этот материал. Требования одного производителя нельзя автоматически распространять на все штукатурные составы.
