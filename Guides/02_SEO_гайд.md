# SEO-гайд BudMachine

Версия: 1.0 · Статус: базовый

## Последовательность

1. Определить главный запрос и интент.
2. Собрать естественные вариации, сущности и связанные вопросы.
3. Спроектировать Title, H1, slug, meta description и H2/H3-карту.
4. Написать полезный материал, затем проверить соответствие метаданных тексту.

## Интент

| Интент | Ожидание | Подход |
|---|---|---|
| Информационный | ответ и объяснение | прямой ответ в начале, гайд, FAQ |
| Коммерческий | сравнение вариантов | критерии, таблица, ограничения |
| Транзакционный | действие | понятные шаги и безопасный CTA |
| Смешанный | изучение и выбор | ответ → варианты → действие |

## Метаданные

- Title конкретен, соответствует странице и не обещает невозможного.
- H1 не дублирует Title механически, но сохраняет тему.
- Description объясняет пользу, а не повторяет набор ключей.
- Основной запрос включается естественно; частотность не является самоцелью.

## Запрещено

Переспам, скрытый текст, вводящие в заблуждение заголовки, нецелевые ссылки и копирование структуры конкурента без собственной пользы.
