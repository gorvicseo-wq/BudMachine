# База знаний BudMachine

Это рабочая база правил, на которую опирается `BudMachine Content Engine v1.0.docx`.

## Как пользоваться

1. Для новой статьи заполните `Шаблон_входных_данных_статьи.docx`.
2. Сохраните файл с новым именем или передайте его вместе с задачей.
3. Движок применяет все гайды из этой папки и фиксирует допущения в карточке результата.

## Структура

| Файл | Назначение |
|---|---|
| `01_Редакционный_гайд.md` | структура, тон, работа с фактами |
| `02_SEO_гайд.md` | интент, семантика, метаданные |
| `03_Гайд_терминологии_и_локализации.md` | русский/украинский язык и единые термины |
| `04_Гайд_визуального_контента.md` | ТЗ, промпты, alt-тексты |
| `05_QA_гайд.md` | контроль качества и статусы выпуска |
| `06_Anti_AI_гайд.md` | редактура шаблонного текста |

## Иерархия правил

1. Закон, безопасность, правила платформы и достоверность.
2. Эта центральная спецификация и актуальные гайды базы.
3. Входная карточка материала.
4. Редакционные предпочтения для отдельного материала.

Если правила конфликтуют, материал не выдаётся как готовый: конфликт и безопасное решение отражаются в QA-итоге.

## Управление базой

Гайды редактируются в Markdown, поэтому их легко искать и обновлять. В начале каждого гайда указаны версия и дата. При существенном изменении добавляйте запись в Update Log центрального документа.
