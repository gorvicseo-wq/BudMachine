# Шаблон входных данных статьи

Скопируйте этот шаблон перед постановкой новой задачи для BudMachine. Заполните только известные параметры: обязательна лишь тема.

## Данные статьи

```
ТЕМА:

ОСНОВНОЙ КЛЮЧ:
(необязательно)

ЯЗЫК:
ru | uk

СТРАНА:
(необязательно)

РЕГИОН:
(необязательно)

ЦЕЛЕВАЯ АУДИТОРИЯ:
(необязательно)

ЦЕЛЬ МАТЕРИАЛА:
информировать | сравнить | помочь выбрать | привести к действию

ОБЪЁМ:
например: 1 800–2 500 слов

ДОПОЛНИТЕЛЬНЫЕ ТРЕБОВАНИЯ:
например: упомянуть конкретный материал, не затрагивать цены, добавить таблицу
```

## Как использовать

1. Вставьте заполненную карточку вместе с задачей.
2. Если поле не заполнено, BudMachine применяет правила из [Master Prompt](../Master%20Prompt.md) и определяет безопасный вариант по теме.
3. Страну, регион и аудиторию лучше указывать, когда от них зависят нормы, цены, материалы или рекомендации.

## Пример

```
ТЕМА: Как подготовить стены под машинную штукатурку

ОСНОВНОЙ КЛЮЧ: подготовка стен под машинную штукатурку

ЯЗЫК: ru

СТРАНА: Украина

РЕГИОН: Киев

ЦЕЛЕВАЯ АУДИТОРИЯ: владельцы квартир перед ремонтом

ЦЕЛЬ МАТЕРИАЛА: информировать

ОБЪЁМ: 2 000–2 500 слов

ДОПОЛНИТЕЛЬНЫЕ ТРЕБОВАНИЯ: добавить чек-лист и таблицу типовых ошибок
```
